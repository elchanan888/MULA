הגדרות וחיבור

חיבור WooCommerce

הפרטים האלו מאפשרים לטעון, ליצור, לערוך ולמחוק מוצרים.

נדרש
כתובת אתר WordPress שבו פועל WooCommerce, כולל https:// וללא נתיב של API.
יצירת מפתחות: בלוח הניהול של WordPress היכנס ל־WooCommerce ← הגדרות ← מתקדם ← REST API, לחץ על הוספת מפתח, בחר משתמש והרשאת Read/Write, והעתק לכאן את ה־Consumer Key וה־Consumer Secret.
המצב האוטומטי בודק קודם את שיטת האימות הרגילה. אם מתקבלת שגיאת 401, הוא בודק פעם אחת את השיטה החלופית, ורק אם הצליחה משתמש בהמשך הסנכרון.
הערת אבטחה: בשיטת Query String המפתחות נשלחים כחלק מכתובת הבקשה. החיבור מוצפן ב־HTTPS, אך כתובות עשויות להופיע ביומני שרת/Proxy. השתמש באפשרות זו רק אם שיטת הכותרת לא עובדת, והימנע משיתוף יומני בקשות או צילומי מסך.

העלאת תמונות מהמחשב

נדרש רק אם רוצים להעלות תמונה חדשה או להחליף תמונה קיימת.

אופציונלי, מומלץ
שם המשתמש לכניסה ללוח הניהול — לא כתובת האימייל בהכרח.
זו לא סיסמת הכניסה הרגילה. אפשר לבטל את סיסמת היישום בכל עת ב־WordPress.
למה צריך את הסיסמה הזו? סיסמת יישום WordPress משמשת רק לאימות מול WordPress REST API, בעיקר להעלאת תמונות לספריית המדיה. היא לא מחליפה את Consumer Key ו־Consumer Secret של WooCommerce, ואינה נדרשת לטעינת מוצרים, קטגוריות או הזמנות. זו סיסמת יישום ייעודית — לא סיסמת הכניסה הרגילה לחשבון.
בדיקה נפרדת מסנכרון WooCommerce.
חשוב בנושא אבטחה: LocalStorage נוח, אבל אינו כספת. כל מי שיש לו גישה לפרופיל הדפדפן או לקוד JavaScript שרץ באתר עלול תאורטית לגשת לפרטים. השתמש באתר HTTPS, שמור את הקובץ והמפתחות מחוץ למאגר ציבורי, אל תשתף משתמשים אחרים באותו ממשק עם מפתחות מנהל, וצור מפתחות בהרשאות המינימליות הנדרשות. לארגון או לאתר רב־משתמשים מומלץ להשתמש בשרת מתווך מאובטח.

ייבוא וייצוא הגדרות

אפשר להדביק בלוק טקסט מלא או JSON. הייבוא שומר את הפרטים בדפדפן הנוכחי.

גיבוי והעברה
ייבוא מקובץ — בלי להעתיק ידניתבחר קובץ JSON / TXT / ENV או גרור אותו לכאן. הקובץ ייקרא מקומית ולא יועלה לשום שרת.
לאחר ההדבקה לחץ על ״ייבוא ושמירה״. אפשר לייבא חלק מהשדות; שדות שלא הופיעו יישארו ללא שינוי.
מבנה ההדבקה ושמות המפתחות הנתמכים

JSON מומלץ — כל חמשת השדות מזוהים ונשמרים בנפרד:

{
  "storeUrl": "https://mulahafakot.com",
  "consumerKey": "ck_...",
  "consumerSecret": "cs_...",
  "wpUsername": "wordpress-login-name",
  "wpAppPassword": "xxxx xxxx xxxx xxxx xxxx xxxx",
  "wooAuthMode": "auto"
}

או טקסט פשוט להדבקה:

STORE_URL=https://mulahafakot.com
CONSUMER_KEY=ck_...
CONSUMER_SECRET=cs_...
WP_USERNAME=wordpress-login-name
WP_APP_PASSWORD=xxxx xxxx xxxx xxxx xxxx xxxx
WOO_AUTH_MODE=auto
שמות המפתחות:
storeUrl / store_url / siteUrl — כתובת החנות.
consumerKey / consumer_key / ck — מפתח WooCommerce שמתחיל בדרך כלל ב־ck_.
consumerSecret / consumer_secret / cs — סוד WooCommerce שמתחיל בדרך כלל ב־cs_.
wpUsername / wp_username / wordpress_username — שם המשתמש של WordPress.
wpAppPassword / wp_app_password / wp_application_password / wordpress_password / wpPassword — סיסמת יישום WordPress בלבד.
אל תכניס כאן את סיסמת הכניסה הרגילה של WordPress. השדה האחרון מיועד ל־Application Password שנוצר בפרופיל המשתמש. אם המבנה שלך כולל wordpress: {"username":"...","password":"..."}, הסיסמה תיובא כשסיסמת יישום; אם מדובר בסיסמה הרגילה — צור סיסמת יישום חדשה במקום זאת.
בחר קובץ או הדבק טקסט/JSON; ניתן להפעיל בדיקת חיבור אוטומטית לאחר הייבוא.
ייצוא הגדרות כולל מפתחות וסיסמת יישום אם נשמרו. קובץ הגיבוי הוא מידע סודי: אל תעלה אותו למאגר GitHub, אל תשלח אותו בצ׳אט ציבורי ואל תשמור אותו בענן משותף.
השינויים לא נשמרו עד ללחיצה על שמירת הגדרות.

הוראות חיבור והפעלה

הגדרה ראשונית בכמה צעדים, ללא התקנת תוכנה נוספת.

חיבור WooCommerce

צריך גישה ללוח הניהול של חנות WordPress שלך.

1

פתח את לוח הניהול

היכנס ל־WordPress של החנות שלך, ובתפריט הצד לחץ על WooCommerce, לאחר מכן על הגדרות.

2

מצא את REST API

בחר בלשונית מתקדם (Advanced) ואז REST API. לחץ על Add key / הוסף מפתח.

3

הפק מפתח עם הרשאה מתאימה

תן תיאור, בחר משתמש שהוא מנהל החנות (Administrator) או בעל הרשאות ניהול WooCommerce, ובחר הרשאת Read/Write. לחץ על יצירת המפתח. העתק מיד את ה־Consumer Key ואת ה־Consumer Secret — הסוד לא יוצג שוב.

4

שמור ובדוק חיבור

חזור לכאן, פתח הגדרות וחיבור, הדבק את כתובת החנות ואת שני המפתחות, ואז לחץ על שמירת הגדרות וחיבור.

5

הגדר תמונות (רק אם צריך)

ב־WordPress היכנס ל־משתמשים ← פרופיל, חפש Application Passwords, צור סיסמה חדשה והעתק אותה יחד עם שם המשתמש להגדרות כאן.

6

ניהול מוצרים וקטגוריות

המוצרים והקטגוריות נטענים מהחנות עם החיבור ומתעדכנים אוטומטית כל חמש דקות. אפשר לשייך קטגוריות, להוסיף מק״ט, ליצור/למחוק קטגוריות ולמיין אותן.

איך לפרסם ב־GitHub Pages

האפליקציה היא קובץ HTML יחיד ואינה זקוקה לבנייה או להתקנת חבילות.

  1. צור מאגר GitHub חדש, רצוי פרטי אם הוא מכיל קוד פנימי (המפתחות עצמם לא נמצאים בקובץ).
  2. העלה את הקובץ הזה ושנה את שמו ל־index.html.
  3. במאגר פתח Settings ← Pages, בחר מקור פרסום מהענף הראשי (לרוב main) ומהתיקייה /(root), ושמור.
  4. פתח את כתובת האתר ש־GitHub Pages מציג והגדר את החיבור. פרטי החיבור נשמרים בדפדפן שבו הזנת אותם, ולא עוברים אוטומטית לדפדפנים אחרים.
אם מתקבלת שגיאת CORS או שגיאת רשת, ייתכן שהשרת/תוסף האבטחה בחנות חוסם בקשות מהדומיין של GitHub Pages. יש לאפשר את מקור האתר שלך בשרת בצורה מצומצמת ומבוקרת. אל תפתור זאת באמצעות חשיפת מפתחות בכתובת URL.

הערות חשובות

כדי למנוע הפתעות בעת ניהול החנות.

  • המחירים מוצגים בשקלים (₪). ודא שמטבע החנות ב־WooCommerce מוגדר לשקל חדש (ILS).
  • מוצר עם וריאציות (Variable product) עשוי לקבל מחירים נפרדים לכל וריאציה. במסך זה ניתן לעדכן את שמו, התיאור והתמונה, אבל שינוי המחיר של הווריאציות צריך להתבצע בממשק WooCommerce.
  • העלאת תמונה דורשת שסיסמת היישום תהיה זמינה ושהמשתמש יהיה מורשה להעלות מדיה.
  • מפתחות API שהוגדרו ב־WooCommerce ניתן לבטל מתוך מסך REST API. מומלץ ליצור מפתח ייעודי לאפליקציה זו.
  • הסנכרון האוטומטי טוען את רשימת המוצרים והקטגוריות בעת פתיחת האתר/חיבורו וכל חמש דקות בזמן שהאתר פתוח. ניתן תמיד ללחוץ על רענון ידני.
  • המק״ט נשמר בשדה SKU המקורי של WooCommerce, והקטגוריות משויכות דרך מזהי הקטגוריות של החנות.
  • כדי להתקין כאפליקציה, העלה את כל קבצי חבילת ה־PWA לתיקיית הפרסום ב־GitHub Pages. בדפדפן נתמך לחץ על ״התקנת האפליקציה״; ב־iPhone אפשר להשתמש בשיתוף Safari ← הוסף למסך הבית.
  • האפליקציה שומרת במטמון רק את מעטפת האתר והאייקונים. מוצרים, הזמנות ונתוני מכירות מחייבים חיבור אינטרנט; פרטי ה־API אינם נשמרים במטמון של Service Worker.
